# Markdown 字数统计器

一个零依赖的 Markdown 字数统计器，使用原生 HTML、CSS 和 JavaScript 编写。

## 功能

- 实时统计总字符数、去除空白后的有效字符数、中文字符数、英文单词数和行数
- 支持加载示例和清空内容
- 响应式布局，手机和桌面浏览器都可以使用
- 不上传文本，内容只在当前浏览器页面中处理

## 本地运行

直接双击 `index.html` 即可打开，也可以在项目目录中启动任意静态文件服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 统计规则

统计基于输入框中的原始 Markdown 文本，Markdown 标记也会计入字符数。中文字符按汉字 Unicode 脚本统计，英文单词按连续的字母或数字统计。
